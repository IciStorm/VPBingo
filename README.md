# VPBingo
Bingo board for Viva Piñata and Viva Piñata: Trouble in Paradise.

Current Implementation Status:
Viva Piñata - Complete!
Viva Piñata: Trouble in Paradise - Not Started

Can also be found at: https://vpbingo.com/

The goal of this project is to make a highly customizable bingo board for use within the Viva Piñata franchise. Settings currently include:

- Table Size, from 3x3 to 7x7
- Bingo Difficulty, from piñata/item levels 1-4, 1-7, or 1-11.
- Force Unique Piñatas, to guarantee each task uses a unique piñata
- Enable Plants, to add plant-based tasks into the bingo pool
- Enable Tinkerables, to add tinkering-based objectives into the bingo pool
- Disable _, to disable any combination of piñata objectives
